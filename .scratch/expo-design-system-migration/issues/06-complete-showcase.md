# 06: Assemble the complete Design System Showcase

**What to build:** The Expo app provides one vertically scrollable Design System Showcase that demonstrates the complete migrated design system through stable component instances and deterministic local fixtures. It is the primary visual and behavioral inspection surface for this phase.

**Blocked by:** 03: Migrate base UI components; 04: Build reusable motion primitives; 05: Migrate app Chrome and overlays.

**Status:** ready-for-agent

- [ ] Showcase sections cover colors, typography, spacing/radius, icons, controls, inputs, surfaces, data, Chrome, and motion.
- [ ] Each section uses stable layouts and deterministic local examples rather than network data.
- [ ] Applicable default, pressed, selected, disabled, error, loading, modal, sheet, and success states are represented.
- [ ] The Showcase is usable on the initial Expo Router route and respects safe-area and scroll behavior.
- [ ] The Showcase does not include Recipe business screens or Web documentation prose.
- [ ] The Showcase provides a coherent end-to-end demonstration of the migrated native design system.
